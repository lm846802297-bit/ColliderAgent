# Freeze merging weight and jet-rate pilot
Question: for the archived (280,1) GeV stau LHE, does each CKKW–L multiplicity have correct per-class weight normalization, and are the same post-shower jet distributions usable for detector validation?
Use 3 shower seeds on the unchanged 1,000 hard events at 20, 30, 40 GeV. Compare native split vs combined weight conventions and single vs two-pass normalization. Requirements: algebraic agreement ≤1e-10 relative for all six nonzero classes, per-jet histogram integral closure, no silent malformed events. Pilot physics gate: n_eff≥25 for every multiplicity/chirality and each reported threshold-neighbor jet-rate bin, inclusive 20/40 rates within 15% of nominal 30 GeV and no >25% per bin above this statistical occupancy. Below-stat bins fail closed. These are development precision targets, not ATLAS prescriptions. Do not forward a matched sample into detector production if these fail. Repeated shower seeds are not independent hard-event samples.
