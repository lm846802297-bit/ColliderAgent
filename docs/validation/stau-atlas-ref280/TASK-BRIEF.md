# ATLAS public gate for direct stau, 280/1 control
Purpose: determine which stages of a 13 TeV CKKW-L/stau-detector workflow can be validated with published evidence before the full five-channel fit. Lock ATLAS HEPData 92006 v2 tables t17/18 and public MadAnalysis5 validation §§7.3/Table 7.2,7.3 (independent author recast but baseline rescaled).
Acceptance for evidence bridge: actual two reference mass points, raw/weighted separation, region order/denominators, known discrepancy controls at both masses. Never promote a baseline-normalized recast to an independent detector response or import the ATLAS likelihood patch as predicted control yield. Record native MG5 stage separately if available. No detector yields/limits until native production and response have been qualified.
