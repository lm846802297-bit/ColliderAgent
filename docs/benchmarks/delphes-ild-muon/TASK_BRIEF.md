# Native Delphes ILD handoff: isolated muons

Purpose: verify the existing native event pipeline can reach a real fast-detector ROOT output, for one narrow μ⁺μ⁻ response diagnostic, without claiming a measured detector performance. Input: exact 128-event QED-FSR-off HepMC3 sample from ColliderAgent 8158d025024363f3870bd0c334a8a19ddc7d2104. Use Delphes 3.5.1 commit 28658365abeb71ee36dfc739f9670c1514c0cb10 and unmodified official ILD card; a wrapper sets only RandomSeed=314159. Use the CERN ROOT runtime in transient scratch after fingerprint verification. Scope: stable truth muon and reco Muon objects; no track studies outside central acceptance, detector calibration or experiment.

Pre-run acceptance: native DelphesHepMC3 must write 128 ROOT entries matching 128 HepMC records with exactly two opposite-sign status 1 truth muons each. For central truth muons |η|<0.7 and pT>20 GeV, require unique same-charge muon identity, preservation of η and φ within 1e-5, and reconstructed efficiency consistent with 0.99×0.95 within five binomial standard errors; use the published card fractional resolution sqrt(0.001²+(10⁻⁵ pT)²) and source log-normal transformation for an independent standardized pT residual. Its mean must be within five standard errors of zero and RMS in [0.65,1.35]. Record the exact binary and ROOT bytes; compare structured outputs on separate seeded replay, not necessarily binary ROOT file metadata. Corrupt input identity must fail. No alternate fake detector model.
