# Model-to-limit benchmark: XENON1T observed elastic SI limit
Purpose: validate a non-collider path from a specified Lagrangian through an
absolute recoil spectrum, response migration, and likelihood to a limit curve.
Read-only references: XENON1T Fig. 5a and v1.0.0 release. The 2018 published
curve is a held-out visual comparison, never an input to the fit.
Acceptance: source identities and same halo/mass conventions; five frozen
rate checks and full-grid source likelihood comparison <1%; zero-coupling
template must be rejected by the limit stage; no claim about full likelihood,
inelastic scattering, or three-body rates. Numerical details in design.json.
Stop after a replayable table and a vector PDF. Do not mutate any main/CI.
