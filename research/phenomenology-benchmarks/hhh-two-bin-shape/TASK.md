# Can a fixed split in m_hhh distinguish the matched-rate benchmarks?
Compare both truth directions with a common channel and background, before
and after profiling. Fix 750 GeV before extracting any differences. Pass if
both profiled two-bin scores gain information relative to single-bin, the
identical-shape negative control passes and two optimizers agree. Assess
absolute separation rather than only relative gain. This scope is an
illustrative statistical stress test, not a prediction from a detector model.
See design.json (written before extraction) for all fixed values and stop rules.
